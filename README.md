# Sottovoce

Audio description for video. A voice tells blind and low-vision viewers what is on screen, in the pauses between the dialogue.

Sottovoce writes each description to fit its pause. A second vision model checks every described fact against the video frames. The finished line is then voiced in Italian or English. A describer reviews and approves every line before export.

All the models run together on one AMD Instinct MI300X.

Status: in development for the AMD Developer Hackathon: ACT III (October 2026).
